# Security Policy

## Supported versions

This project is pre-1.0 and under active development. Only the latest commit
on `main` receives fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Instead, use GitHub's private vulnerability reporting on the
[Security tab](https://github.com/ruhansachdeva/Imagination-Sandbox/security/advisories/new),
or contact the maintainer directly.

Please include:

- what the issue is and roughly how severe you think it is,
- the steps needed to reproduce it,
- the commit or version you tested against.

Expect an acknowledgement within a week. Since this is a hobby project
maintained in spare time, fixes are best effort.
